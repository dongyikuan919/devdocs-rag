## 直接使用

- 阅读和后续检索只选 `documents/*.md`，这 15 个文件是已整理的文本知识正文。
- `originals/*.mdx` 为逐字节保留的官方原文；已验证 Git blob SHA，与所标记的上游版本一致。
- `sources.json` 保存每篇的来源、主题、产品范围、原文件路径、版本和 SHA-256，便于更新和溯源。
- 许可、索引、清单与原始文件单独保存，避免与 `documents/` 重复导入。

整理保留了原文步骤、FAQ 问题、表格、警告和已有的 AI 翻译说明；去除了 MDX 展示组件和独立截图引用，补充来源与许可，并将相对站内链接转换为完整链接。表格中的 HTML 列表转换为行内分隔。未下载截图，未改写产品事实。

## 使用限制

这批文档代表固定提交的历史快照。套餐、配额和账单规则可能变化，问答应标明资料版本，实际购买与操作以官方最新信息为准。多数中文页由上游标注为 AI 自动翻译，需要核实时可沿原文中的链接查看英文版。

这里只准备了知识资料；尚未建立向量索引、调用模型或验证端到端问答效果。后续模拟工单与模型训练数据需另行准备，并与本产品文档分开标注。
