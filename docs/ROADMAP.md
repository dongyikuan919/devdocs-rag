# 企业知识库智能客服：开发里程碑

目标：完成一个 Java 为主、可以演示与开源的 AI 项目。用户每周可投入约 8 小时，协作以可运行成果推进；早期按周学习的计划已由本里程碑方案替代。

## M1：Java 工程与模型接入

- 建立 Spring Boot / Spring AI 工程并锁定兼容的依赖版本。
- 配置项目 JDK、服务端模型配置、健康检查和基础异常反馈。
- 建立关键流程的自动检查，确认本地构建和运行步骤。
- 使用实际模型服务完成一次调用；未配置凭据时明确说明状态。

验收：工程能够构建和启动；可以按说明运行一次模型调用，并验证配置缺失和调用失败的反馈。

## M2：文档导入与可追溯问答

- 导入现有 15 篇 Dify Cloud 中文文档，仅处理 documents 目录，来源与版本读取 sources.json。
- 按标题和段落切块，保存元信息，生成 Embedding 并建立向量索引。
- 完成问题检索、基于证据的生成和引用片段展示；重复导入不增加相同知识。
- 资料不足时明确反馈；外部正文作为证据数据处理，不能变更系统指令。

验收：同一问题可追踪到检索片段与原文；固定的知识未覆盖案例有明确反馈，正常问题的答案可人工核查。

## M3：完整演示与开源发布

- 提供问答页面，展示回答、来源、资料版本与处理状态。
- 准备至少 30 个固定问题，覆盖可回答、跨段落、知识未覆盖和干扰输入。
- 记录回答质量、引用支撑、失败情况、模型与提示版本、耗时和用量，保留基线对比与失败案例。
- 补齐关键测试、配置示例、可复现启动步骤、演示与架构说明，发布 v0.1。

验收：从干净环境可按 README 复现完整问答链路；公开的效果数字来自实际评测；CI 使用离线样例或模型替身，在线评测单独触发。

## 后续增强：按评测与使用反馈选择

- 检索优化：查询改写、混合检索或重排，先证明对固定问题集有帮助。
- 客服工具：在本项目增加模拟服务工单查询、信息补问与人工接手摘要；身份与工单归属由服务端验证。
- 专项微调：有足够的人工审核数据且确有需求时，再评估意图分类或字段提取；不作为首版交付前提。
