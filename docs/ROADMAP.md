# 开发文档问答库：阶段路线图

当前状态：初始化完成，开发尚未开始。以下任务均为计划。

整体路线：文档问答 → 工具助手 → 小模型微调实验。三个项目分别交付，按验收推进。

| 周 | 要学什么 | 当周可检查的产出 |
| --- | --- | --- |
| 1 | Token、上下文、模型推理与训练的区别、HTTP/JSON、API 密钥管理 | 写清一个使用场景和 10 个真实问题，跑通最小模型调用；记录一次调用的耗时和用量 |
| 2 | Prompt、示例提示、结构化输出、基本 Transformer/Attention 概念 | 一个可重复运行的问答脚本，对固定输入比较两种提示；能解释模型为什么可能编造答案 |
| 3 | Embedding、相似度、切块与检索 | 导入 10～20 份自写或许可允许的短文档；输出检索段落及文件/章节来源 |
| 4 | RAG：先检索，再带证据生成 | 完成文档问答与简单页面；没有足够依据时不编造来源 |
| 5 | 检索质量与回答质量的区别、错误分析 | 固定至少 30 道评测问题，比较直接问模型与 RAG，记录错误类型和改动前后结果 |
| 6 | 可复现安装、开源文档和发布 | 项目一 v0.1：从干净环境按 README 跑通示例，提交演示、评测报告和已知限制 |

## 首版交付要求

- README 中说明实际可用的功能、运行步骤和限制。
- 提供可公开的示例输入与输出。
- 保留评测用例、结果和失败案例。
- 普通自动检查使用离线样例；在线模型评测单独运行，避免自动消耗 API 配额。
- 在干净环境中复核运行步骤后再发布 v0.1。
